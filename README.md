# grafana
This **Grafana Dashboard JSON** can be used to proactively monitor and analyze prometheus memory and CPU alerts, providing better visibility into recurring issues and improving operational efficiency.

The dashboard offers the following capabilities:

- **Centralized Monitoring:** Provides a single view of all active memory and CPU alerts, along with their respective namespaces and pod names, eliminating the need to check multiple alerts individually.
- **7-Day Alert Trend Analysis:** Enables the team to track memory and CPU alert trends over the last 7 days to identify frequently impacted applications and pods.
- **Visual Identification of Recurring Issues:** If 5–6 pods belonging to the same application trigger alerts within the last 7 days, the dashboard highlights the trend with a **red line**, making recurring issues easier to identify.
- **Proactive Monitoring:** Helps the team identify potential issues early, investigate recurring alerts, and take preventive action before they lead to further incidents.

**Overall, the objective is to consolidate critical monitoring information into a single pane of glass**, reducing manual effort, saving time, and enabling the team to identify trends, prioritize investigations, and take proactive measures more efficiently.
